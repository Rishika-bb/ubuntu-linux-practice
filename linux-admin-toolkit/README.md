# Linux System Administration Toolkit

A collection of Bash scripts and Linux documentation for basic system administration and monitoring.

## Features

- System information
- Disk usage monitoring
- Process monitoring
- Project backup
- Network information
- ShellCheck automation using GitHub Actions

## Scripts

- `system-info.sh` - Displays basic system information
- `disk-monitor.sh` - Monitors disk usage
- `process-monitor.sh` - Displays running processes
- `backup.sh` - Creates a backup of the project
- `network-info.sh` - Displays network information

## Documentation

Linux commands and system administration notes are available in `documentation/commands.md`.

## GitHub Actions

ShellCheck automatically checks Bash scripts whenever code is pushed to GitHub.
